## Trace an issue

Capture the command or endpoint, component versions, public IDs, and sanitized error. Use the component's README and focused tests to verify the behavior. If a public contract changes, update the affected procedure and reference in the user guide. See [Contribute to MirrorNeuron](./contributing.mdx).
