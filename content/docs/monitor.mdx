title: "Monitor and control runs"
description: "Find a run, follow progress, collect outputs, and respond to requests."
---

Keep the run ID returned by `mn blueprint run` or `mn job start`. To find a run from a saved job, use `mn run list --job <job-id>`.

## Monitor in the Web UI

Open the Web UI address reported by `mn runtime status` on a combined installation. Use **Dashboard** to check the connection and runtime health. Open **Jobs** to see saved definitions or **Runs** to open one execution. The run detail shows state and workflow activity. A job that provides its own UI may also expose a separate job page.

## Runtime and run state

Use the public run ID with the attached CLI to check status and follow activity.

```bash
mn run show <run-id>
mn run watch <run-id>
```

Ctrl+C detaches the watcher. The run continues on its owner. If it shows `queued`, inspect the owner, queue position, and blocker. See [Schedules and events](./schedules-and-events.mdx#inspect-or-defer-a-queued-run) to defer a queued start or cancel it before admission.

## Logs, events, and results

```bash
mn run logs <run-id> --channel all --follow
mn run resources <run-id>
mn run result <run-id>
```

Use `--channel logs` for worker logs and `--channel events` for recorded state changes. `mn run result` downloads files to the client's `$MN_HOME/outputs/<run-id>`. Use `--output ./results` to choose another destination. Verify the reported downloads and review the output before using it.

For a blueprint report, use `mn blueprint export <run-id> --format markdown --output report.md`. Preserve logs, timestamps, and artifacts when investigating a failure.

## Control

```bash
mn run pause <run-id>
mn run resume <run-id>
mn run cancel <run-id>
```

A paused run can still hold capacity. Cancel unfinished work if it should stop. Handle any external effects already performed in the external system. To continue an eligible failed run from a saved checkpoint, see [Manual checkpoint retry](./reliability.mdx#manual-checkpoint-retry).

> Deleting a run permanently removes its stored data. An active run is cancelled as part of deletion. Download the files you need before confirming.

```bash
mn run delete <run-id> --dry-run
mn run delete <run-id> --yes
```

## Human collaboration

List pending requests first. After reviewing the details, choose the appropriate response or acknowledgement command.

```bash
mn run human list <run-id> --pending
mn run human respond <run-id> <request-id> --decision approve
mn run human ack <run-id> <notice-id>
```

Use the request ID for a decision and the notice ID for an acknowledgement. If progress stops after you respond, check [Troubleshooting](./troubleshooting.mdx).
