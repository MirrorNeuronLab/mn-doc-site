MirrorNeuron Runtime runs packaged workflows called **blueprints**. Start on one machine or connect several runtime nodes. Use the Web UI to inspect jobs and runs, the `mn` CLI to operate the runtime, or the HTTP API and Python SDK to integrate your application.

## Start here

1. [Install MirrorNeuron](./installation.mdx) on your machine or connect a client to an existing runtime.
2. [Run your first blueprint](./quickstart.mdx) with sample inputs.
3. [Find the run and download its results](./monitor.mdx).
