---
title: "Runtime configuration"
description: "Find common settings for clients, listeners, catalogs, capacity, and storage."
---

Set each value where the component runs. Client settings apply to the CLI or API process. Capacity, service, and shared storage settings belong on the owning runtime. Before changing an existing installation, record its current settings securely and check `mn runtime status`. Use the installed `bin/mn-runtime` lifecycle on a dedicated runtime.

## Installation and connection

| Setting | Default or source | Use |
| --- | --- | --- |
| `MN_HOME` | `~/.mn`, `~/.mn-client`, or `~/.mn-runtime` | Select the installation directory. |
| `MN_ENV` | `dev` | Select the configuration environment. Production API processes require a token. |
| `MN_GRPC_TARGET` | `localhost:55051` fallback | Set the endpoint for direct Python SDK access. |
| `MN_GRPC_AUTH_TOKEN` | Installation or environment | Authenticate direct SDK calls to Core. Keep this value private. |
| `MN_GRPC_TIMEOUT_SECONDS` | `10` | Set the direct SDK request timeout in seconds. |
| `MN_GRPC_PORT` | `55051` | Publish Core on this host port. |
| `MN_GRPC_BIND_HOST` | `127.0.0.1` in the Compose configuration by default | Choose the interface for the Core listener. |

Use `mn node add` to set the CLI and API connection. It saves the validated endpoint and runtime credential in `$MN_HOME/client.json`. See [Connect a client without Docker](./installation.mdx#connect-a-client-without-docker).

## API and Web UI

| Setting | Default or source | Use |
| --- | --- | --- |
| `MN_API_HOST` | `localhost` in the API, `127.0.0.1` for a client install | Set the API bind host. An installer with the Compose Web UI can set `0.0.0.0`. |
| `MN_API_PORT` | `54001` | Set the API port. |
| `MN_API_TOKEN` | `$MN_HOME/api.token` when available | Set the API bearer token. Client and production API processes require one. |
| `MN_API_CORS_ALLOW_ORIGINS` | Empty | Allow specified origins with a comma-separated list. |
| `MN_API_REQUEST_SIZE_LIMIT_BYTES` | `5242880` | Limit ordinary request bodies. Bundle uploads and backup restores have their own limits. |
| `MN_API_BLUEPRINT_UPLOAD_LIMIT_BYTES` | `34359738368` | Set the maximum bundle ZIP size, capped at 32 GiB. |
| `MN_WEB_UI_HOST` | `localhost` | Set the host used in Web UI endpoint reporting. |
| `MN_WEB_UI_PORT` | `55173` | Set the Web UI port. |
| `MN_WEB_UI_BIND_HOST` | `127.0.0.1` | Choose the Compose host interface for the Web UI. |

Review [listener access](./security.mdx#local-defaults-and-listener-checks) before publishing ports outside loopback.

## Blueprint catalog resolution

| Setting | Default | Use |
| --- | --- | --- |
| `MN_BLUEPRINT_SOURCE` | `github` | Select `github` or `local`. |
| `MN_BLUEPRINT_REPO` | `https://github.com/MirrorNeuronLab/mn-blueprints.git` | Select the Git catalog. |
| `MN_BLUEPRINT_LOCAL` | Unset | Select a catalog directory with `index.json` for `local` mode. |
| `MN_BLUEPRINT_REPO_CACHE` | `~/.cache/mirror-neuron/blueprint-repos` | Set the Git catalog checkout cache. |

The CLI list and API catalog list read the catalog configured on their surface. Catalog launch and preparation resolve packages on the connected runtime. If you use a custom catalog, configure both where needed so IDs shown in the list are available to launch. Local directories must be readable on the machine using them.

## Execution and storage

| Setting | Default or source | Use |
| --- | --- | --- |
| `MN_REDIS_URL` | Deployment-specific | Connect the owning Core to Redis. |
| `MN_REDIS_NAMESPACE` | `mirror_neuron` | Set the key namespace. Each federated runtime needs a distinct writable store identity. |
| `MN_EXECUTOR_POOL_CAPACITIES` | Unset | Set named executor slot limits, for example `default=4,gpu=1,io=8`. |
| `MN_AUTO_PORT_START` / `MN_AUTO_PORT_END` | `49152` / `65535` | Set the automatic port allocation range. Publish needed listeners through the runner. |
| `MN_SHARED_STORAGE_ROOT` | `$MN_HOME/shared` | Select the shared file root. |
| `MN_BLUEPRINT_PYTHON_ENVS_DIR` | `$MN_HOME/cache/blueprint-python-envs` | Select a node-local HostLocal environment cache. |
| `MN_SYNCTHING_REQUIRED` | Unset | Require the shared storage sidecar for startup or join when configured. |
| `MN_CONTEXT_AUTH_TOKEN` | Installation-specific | Authenticate access to the context service. |

Use [Resources and devices](./resources-and-devices.mdx) for per-run reservations and [Redis failover](./redis-ha.mdx) for Sentinel configuration.

## CLI output and logs

Set `MN_CLI_OUTPUT=plain` for plain terminal output. `MN_LOG_LEVEL` defaults to `INFO` and `MN_LOGS_ROOT` defaults to `$MN_HOME/logs`. Check the affected component after restarting it with the new configuration. For a catalog change, list the catalog and inspect a matching blueprint on the connected runtime.
